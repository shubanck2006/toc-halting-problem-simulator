Formal comparison of $R$ and $RE$

Theory reference
Property Recursive language (decidable, $R$) Recursively enumerable language (Turing recognizable, $RE$)
Machine type A Turing machine that is a decider (total Turing machine). A standard Turing machine, also called a recognizer or semi decider.
Behavior on $w \in L$ Halts and accepts Halts and accepts
Behavior on $w \notin L$ Halts and rejects in finite time. May loop forever and never returns a definitive no.
Decidability status Decidable and solvable. Partially decidable or semi decidable.
Closure under complement Closed. If $L \in R$, then $\overline{L} \in R$. Not closed. $L \in R \iff (L \in RE \text{ and } \overline{L} \in RE)$.
Chomsky hierarchy A strict subset of type 0 languages. Exactly equivalent to type 0 (unrestricted grammars).
Real world analogy A compiler syntax checker that always finishes and prints yes or no. A search engine looking for one specific star in an infinite universe.
