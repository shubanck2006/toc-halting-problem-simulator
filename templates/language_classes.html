Formal Comparison: Recursive ($R$) vs. Recursively Enumerable ($RE$) TOC Theory Reference
Property Recursive Language (Decidable, $R$) Recursively Enumerable Language (Turing-Recognizable, $RE$)
Machine Type Turing Machine that is a Decider (Total Turing Machine). Standard Turing Machine (Recognizer or Semi-Decider).
Behavior on $w \in L$ Halts and Accepts Halts and Accepts
Behavior on $w \notin L$ Halts and Rejects in finite time. May loop forever! Never returns a definitive "NO".
Decidability Status Decidable / Solvable. Partially Decidable / Semi-Decidable.
Closure Under Complement Closed. If $L \in R$, then $\overline{L} \in R$. NOT closed. $L \in R \iff (L \in RE \text{ and } \overline{L} \in RE)$.
Chomsky Hierarchy Strict subset of Type-0 (decidable subset). Exact equivalent to Type-0 (Unrestricted Grammars).
Real-World Analogy A compiler syntax checker that always finishes and prints YES/NO. A search engine looking for a specific star in an infinite universe.
