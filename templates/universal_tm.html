The stored program revolution (Alan Turing, 1936)

Prior to 1936, calculating machines were built for a single fixed task such as adding or weaving. Alan Turing proved that a single machine $U$ could simulate any arbitrary machine $M$, provided that the rules of $M$ are encoded as binary data on the tape. This theoretical breakthrough is the direct ancestor of modern programmable computers.

Format: transitions separated by 00, machine and input separated by 000.
Formal encoding $\langle M, w \rangle = \langle M \rangle 000 \langle w \rangle$ Standard TOC binary encoding

Transitions are encoded as $1^{i+1} 0 1^j 0 1^{k+1} 0 1^l 0 1^m$, separated by 00. The machine description $\langle M \rangle$ and encoded input $\langle w \rangle$ are separated by 000.
