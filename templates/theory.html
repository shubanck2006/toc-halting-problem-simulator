The Church and Turing thesis

Fundamental hypothesis
"Every effectively calculable function or algorithm can be computed by a Turing machine."

In 1936, Alonzo Church, working with the lambda calculus, and Alan Turing, working with Turing machines, set out to formalize the intuitive notion of an algorithm or effective procedure. They found that the two formalisms, despite looking radically different, computed exactly the same class of functions.

Why a thesis, not a theorem

An algorithm is an informal human concept, so the claim cannot be proven like a mathematical theorem. Every formal model of computation invented in the last 90 years has nonetheless proven equivalent to Turing machines.

Modern equivalence

C++, Python, Java, quantum computers, and multicore supercomputers cannot decide any language that a basic single tape Turing machine cannot decide. A problem that is undecidable for a Turing machine is undecidable for every computer.

Proving the limits of software

The thesis lets computer scientists establish firm physical and mathematical limits on all future software by reasoning about seven tuple Turing machines.

Countability and Cantor diagonalization

Cardinality of infinities

Georg Cantor proved that infinite sets have different sizes. The set of all possible Turing machines is countably infinite ($\aleph_0$), while the set of all possible languages is uncountably infinite ($2^{\aleph_0}$).

Deduction
  1. Every Turing machine $M$ has a finite string description $\langle M \rangle \in \Sigma^*$.
  2. The set of all finite strings over a finite alphabet is countably infinite, $|\Sigma^*| = \aleph_0$.
  3. The set of all possible Turing machines is therefore countable, $|\{ \text{All TMs} \}| = \aleph_0$.
  4. A language is an arbitrary subset of $\Sigma^*$, so the set of all languages is $\mathcal{P}(\Sigma^*)$.
  5. By Cantor's theorem, $|\mathcal{P}(\Sigma^*)| = 2^{\aleph_0} > \aleph_0$, which is uncountably infinite.

Because $2^{\aleph_0} \gg \aleph_0$, there are vastly more languages than Turing machines, and almost all problems have no algorithm at all.

Cantor's diagonalization demonstration

Suppose someone claims to have an exhaustive enumerated list $s_1, s_2, s_3, \dots$ of all infinite binary strings. By flipping the bit at index $i$ of string $s_i$, Cantor constructs a new string $D$ that differs from every string in the list.

Variants of Turing machines

Equivalence of models

A central result of automata theory is that modifying the physical architecture of a Turing machine, by adding more tapes, more tracks, or nondeterminism, never increases its computational power.

Multitape Turing machines

The machine has $k$ independent tapes, each with its own read and write head.

Equivalence proof

A single tape machine simulates $t$ steps of a $k$ tape machine in $O(t^2)$ time by interleaving $2k$ tracks on one tape, one track for symbols and one track for virtual head markers.

Nondeterministic Turing machines

The transition function $\delta$ branches into several valid choices at each step.

Equivalence proof

A deterministic three tape machine simulates a nondeterministic machine with breadth first search over the branching tree. Any language decided by a nondeterministic machine is decidable by a standard deterministic machine.

Two way infinite tape

The tape extends infinitely toward $-\infty$ and $+\infty$.

Equivalence proof

A standard semi infinite tape machine folds the tape at cell 0, using track 1 for positive indices $[0, 1, 2, \dots]$ and track 2 for negative indices $[-1, -2, \dots]$.

Multitrack Turing machines

A single tape is divided into $k$ parallel tracks with one unified head.

Equivalence proof

Storing $k$ symbols per cell is equivalent to expanding the finite tape alphabet to $\Gamma' = \Gamma^k$, which preserves exactly the same computational power.

Rice's theorem

Semantic undecidability
"Any nontrivial semantic property of the language recognized by a Turing machine is undecidable."

Rice's theorem shows that the halting problem is not an isolated exception. Every question about the actual behavioral outcome of a program is undecidable.

Interactive Post Correspondence Problem

Combinatorial undecidability

Given a collection of dominoes with a top string and a bottom string, can you find a sequence of dominoes, with repeats allowed, whose concatenated top string equals the concatenated bottom string? Emil Post proved in 1946 that deciding whether a match exists is undecidable.

Catalog of classical undecidable problems

Reductions

Once the halting problem was proven undecidable, mathematicians and computer scientists proved dozens of other fundamental problems undecidable through mapping reductions ($A \le_m B$). If solving $B$ would let you solve $A$, then $B$ must also be undecidable.

Problem name Formal language definition Status Reduction and proof sketch
Halting problem ($H_{\text{TM}}$) $\{ \langle M, w \rangle \mid M \text{ halts on } w \}$ Undecidable, $RE$ Turing diagonalization and a self referential paradox.
State entry problem $\{ \langle M, w, q \rangle \mid M \text{ enters } q \text{ on } w \}$ Undecidable Reduce from $H_{\text{TM}}$ by rewriting halting states to point directly to $q$.
Blank tape halting problem $\{ \langle M \rangle \mid M \text{ halts on an empty tape } \}$ Undecidable Construct $M'$ that writes $w$ on the tape first, then transfers control to $M$.
Emptiness problem ($E_{\text{TM}}$) $\{ \langle M \rangle \mid L(M) = \emptyset \}$ Undecidable, not $RE$ Construct $M'$ that ignores its input, simulates $M$ on $w$, and accepts when $M$ accepts.
Equivalence problem ($EQ_{\text{TM}}$) $\{ \langle M_1, M_2 \rangle \mid L(M_1) = L(M_2) \}$ Undecidable, not $RE$ Reduce from $E_{\text{TM}}$ by letting $M_2$ reject every input string.
CFG ambiguity problem $\{ \langle G \rangle \mid \text{CFG } G \text{ is ambiguous} \}$ Undecidable Reduction from the Post Correspondence Problem.
