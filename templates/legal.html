Educational purpose

The simulator exists to teach Turing machines, universal computation, and the undecidability of the halting problem. It is a study aid, not a production decision tool and not a formal proof assistant.

The simulator does not decide halting

Every run stops at a step limit. When a machine reaches that limit the interface reports STEP_LIMIT_REACHED. That status means the run was cut short. It is not a claim that the machine loops forever, and it should never be presented as one.

The hypothetical halting detector shown in the proof pages is a mathematical device used to reach a contradiction. It is not an implemented oracle.

The short version

This simulator sets no tracking cookies, runs no analytics, and sends no telemetry. There are no accounts, no advertising, and no profiling. Input strings stay in your browser until you choose to run them against the local Flask process.

What stays on your machine

Machine definitions, tape contents, transition tables, and proof settings are handled in memory by the Flask application that you start yourself. The project does not upload them to a remote database. The local server may print request lines to your terminal while it runs. Those lines remain on the machine that hosts the app and are not collected by the project.

Cookies and browser storage

The application does not set cookies, does not use local storage for tracking, and does not fingerprint your browser. If you clear site data you will simply lose any preferences your browser kept for you, not a profile held by the project.

External assets

Pages load a few public assets over the network: Geist and Geist Mono from Google Fonts, Phosphor icons from a public content network, and the Mermaid and MathJax libraries that render diagrams and mathematics. Those providers receive the request for the asset, including your IP address, under their own privacy policies. The project does not pass your simulator input to them.

Children and sensitive data

The tool is written for undergraduate study. Please do not paste personal, medical, or otherwise sensitive information into an input string. It is not needed for any exercise, and the simulator treats input as plain tape symbols.
